How it works and limits

Images are drawn only from the 3,421-image TEST split. Drawing is quantized to the original 28×28 RGB pixels; transformation controls operate on that edited canvas rather than accumulating across requests. All three actual checkpoints run on every submitted input with their original preprocessing (ResNet18 nearest224, ResNet50 native28, ViT local processor224). Noise is deterministic for seed42, image ID and level. Edits can change the label or leave the data distribution; the original truth label is not automatically valid after editing. This app runs locally, does not train models and does not upload images to an external service.
