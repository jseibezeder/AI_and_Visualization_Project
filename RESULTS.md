# Final results and reading guide

## Supported workflow

From the repository root, use an isolated Python environment with `requirements.txt`
installed, run `git lfs pull` if checkpoints are pointers, and select that environment's
Python kernel in JupyterLab. Run in this order:

1. **`predictions.ipynb`** — validate the three frozen TEST baselines, indices/labels,
   probability/logit consistency and checkpoint/configuration hashes. The default
   performs no inference or writes; optional full-TEST checkpoint replay is explicitly
   disabled and verifies rather than replaces the published predictions.
2. **`confidence_analysis.ipynb`** — four connected stories: disagreement, confidence,
   destabilizing changes and observable error properties; then the focused IG/neutrophil
   characterization and model-specific conclusions.
3. **`stability_analysis.ipynb`** — the two canonical full-test transformation grids:
   label-change rate and accuracy. The confidence notebook links here instead of
   duplicating those curves.

These default executions use committed binary caches and only the **3,421 TEST images**.
They require no training, network downloads, live service or new model queries.
The self-contained `visualizations/transformation_explorer.html` provides all eight
transformations and ten severities, with linked zoom and exact recovery/new-error
accounting. Its data are regenerated by the confidence notebook; static results remain
readable without JavaScript.

`archive.ipynb` is a historical record, **not a Run-All entry point**. It preserves
complete earlier code/plots/interpretations, including superseded claims, train/validation
exports, entropy/PCA work and the old `visualization/predictions.ipynb`. That legacy
notebook now redirects to the supported workflow instead of mixing an older ResNet50
result with the final pipeline. The optional live editor/workbench is not required
or used as evidence; unfinished workbench changes remain separate from this finalization.

## What the evidence supports

| Pipeline | TEST accuracy | HC errors (confidence ≥90%) | Main distinction |
|---|---:|---:|---|
| ResNet18, nearest224 | 96.61% | 70 | Strong native brightness/color/noise sensitivity; IG has its highest class-conditioned HC-error rate. |
| Supplied ResNet50, native28 | 95.73% | 79 | Largest ECE and strong rotation sensitivity; +20° introduces 668 errors while recovering 60. |
| Original local ViT, bilinear224 | 96.99% | 52 | Better native brightness/noise behavior here, but strongest-blur accuracy falls to 52.3%. |

- Model agreement and confidence are not correctness guarantees: all three share
  18 confidently wrong images with identical wrong labels.
- Robustness depends on the checkpoint **and preprocessing**. Common interpolation
  narrows the selected noise-loss gap but changes clean accuracy; different transformation
  ranges are not equal-strength perturbations.
- Broad saturation reduction sends both CNN cohorts toward erythroblast. Tighter
  confidence matching does **not** support the older claim of extra central dependence
  in HC errors; approximate ROI effects cannot establish anatomical localization.
- The IG→neutrophil direction shows clearer appearance differences than the reverse
  direction. The justified conclusion is a selected-cohort association, not a nuclear
  mechanism, a label-error diagnosis or a demonstrated corrective intervention.

## Important limits and stopping point

The cohorts and hypotheses were selected after inspecting TEST behavior. Bootstrap
intervals keep images/pairs together and average repeats/patches within images, but
condition on the chosen cohort, exclude training/annotation/matching uncertainty and
are not corrected for multiple comparisons. Small class strata can yield degenerate
intervals. RGB features are correlated; masks are approximate, doses unequal and
synthetic edits can invalidate the original labels.

A focused saturation intervention on the tight IG/neutrophil pairs was **not** run;
the broader saturation cohort cannot substitute for it. Original-resolution,
subtype-resolved expert review and training/preprocessing-controlled comparisons
would address other unresolved causal questions. These are reasonable future studies,
not grounds to add more exploratory experiments to the completed descriptive Phase I.
