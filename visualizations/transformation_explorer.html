Definitions and limits

The unmodified prediction defines the starting correct/wrong group separately for each model. New errors and recoveries are counted among all test images, not normalized by the two different starting group sizes. A wrong-to-different-wrong switch changes neither correctness nor accuracy and is not counted here. A confidently wrong prediction already present before transformation is not a new error. A modified image can leave the data distribution or change the label, so these are exploratory checkpoint responses, not a recommended correction strategy.
